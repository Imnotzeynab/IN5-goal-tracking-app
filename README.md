IN5 is a goal-tracking web application designed to help users plan, organize, and track their long-term goals over a 5-year period.

The goal of IN5 is to help users turn ambitious ideas into actionable steps by tracking progress and staying focused
Features:

- User authentication (login system)
- Create personal goals
- View saved goals
- Update goal progress
- Delete goals
- Track progress visually
- Store data using SQLite database

Technologies Used:

-Python
Flask
SQLite
