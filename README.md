
IN5 is a personal goal-tracking desktop application designed to help users set, track, and visualize their long-term goals.

The idea behind IN5 is to help users stay consistent by turning goals into daily actions and tracking progress over time.

Features

- User registration and login system
- Create personal goals
- View saved goals
- Update goal progress daily
- Delete goals
- Visualize progress with charts
- Store user and goal data locally using SQLite

Technologies Used

- Python - Main programming language
- Tkinter - Graphical User Interface (GUI)
- SQLite - Local database management
- Matplotlib - Data visualization and progress charts
- Datetime - Date tracking and goal updates
